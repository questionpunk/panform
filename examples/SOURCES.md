# Example fixtures: provenance and licences

A per-file register for everything under `examples/`, for deciding what can
ship if the repository is open-sourced. The panform code is MIT. Nothing here
has been published.

Checked on 2026-09-27. For every copied file, the local copy was compared
byte for byte with the upstream file at the commit given; "unmodified" means
the bytes match. Upstream licences were read from the upstream repository's
licence file (via the GitHub API) or from the publisher's own page. The
fourteen files that check flagged were resolved on 2026-11-10; what was done
to each is listed after the tables.

**Status.** `ok` means the file is MIT, or its licence allows redistribution
inside an MIT repository given the attribution noted. `ok (GPL)` means the
file is GPL-2.0-or-later and sits in `examples/gpl/`, which carries its own
licence text and is not part of the MIT-licensed work.

Totals: 40 fixtures. 25 written for panform (MIT), 13 copied under
permissive licences and 2 copied under the GPL in `examples/gpl/`.

## How the flagged files were resolved (2026-11-10)

The 2026-09-27 check flagged fourteen files whose licence was GPL,
share-alike, non-commercial, proprietary or unknown. None is flagged now.

**Replaced with original content (now MIT).** Each replacement was written
for panform, keeps the format features the old file exercised, and copies no
text from the old file or from any other project.

- **`cars.gift`**: the true/false item and the two `Trivia` items came from
  the Moodle GIFT documentation (GPL). They were replaced with original
  questions of the same kinds.
- **`cars.qmd`**: the matrix and the numeric question were copied from the
  surveydown website (CC BY-NC-SA 4.0). They were rewritten with new ids and
  labels.
- **`quiz.aiken.txt`**: both questions were the Moodle Aiken help example
  (GPL). They were replaced with two original questions in the same shape.
- **`commute.bla`**: the title and question texts followed the Blaise 4.5
  Developer's Guide (no licence found). The model title, every field and
  enumeration name and every text are new; the constructs are the same.
- **`limesurvey/colors.limesurvey.txt`**: a TSV from a LimeSurvey testing
  repository that granted no licence. It was replaced with an original survey
  in the same layout, including original email templates in place of
  LimeSurvey's defaults.
- **`household-finance.ddi.xml`** replaces `findex-2025-excerpt.ddi.xml`, an
  excerpt of a World Bank Microdata Library DDI export whose terms do not
  allow redistribution. The study, variables and question texts are invented.
- **`qti-samples.qti.xml`**: seven IMS/1EdTech sample items (derivatives not
  permitted; two also carried a Cambridge ESOL copyright). They were replaced
  with seven original items of the same interaction types.
- **`qualtrics-advanced.qualtrics.txt`**: the first half followed the
  Qualtrics support file "AdvancedExample.txt". Every embedded-data name,
  block name, question text, choice and statement was rewritten; only the
  `[[...]]` tags, which are the format's syntax, are the same.
- **`msforms/basic-types.msforms.json`** (was `basic-types-2022`),
  **`msforms/sections.msforms.json`** and **`msforms/branching.msforms.json`**:
  captured forms from third-party repositories with no licence. Each was
  replaced with a synthetic form in the same wire shape, with invented texts
  and placeholder ids (see `msforms/SOURCE.md`).

**Kept under the GPL, in a separate directory.**
`limesurvey/ls2-group-relevance.lss` and
`limesurvey/ls4-answer-options-multilingual.lss` are verbatim LimeSurvey
files under GPL-2.0-or-later. They moved to `examples/gpl/limesurvey/`.
`examples/gpl/README.md` states the copyright, licence, upstream path and
commit, and that the directory is test data aggregated alongside panform and
not part of the MIT-licensed work. `examples/gpl/COPYING` is the GPL-2.0
text.

**Kept with attribution.** `openstatspec-dictionary.sps`: the upstream
repository has declared Apache-2.0 in its `pyproject.toml` since commit
`830f79406a`, and the `.sps` file is identical on main.
`openstatspec-dictionary.LICENSE` gives the source, the commit and the
licence text.

**Git history.** The replaced files are still in the commits before this
change. Publishing the repository with its history would publish them too, so
publish from a fresh history, or rewrite it, if they must not be distributed.

## Personal data scan

Every fixture was searched for email addresses, phone numbers, personal
names outside public contexts, owner or tenant identifiers, and response
data.

- **`household-finance.ddi.xml`**: names only an invented organisation and
  the placeholder `surveys@example.com`. The file it replaced
  (`findex-2025-excerpt.ddi.xml`) named a World Bank staff member as a
  contact; that file is no longer in the tree.
- **`msforms/basic-types.msforms.json`, `msforms/sections.msforms.json`,
  `msforms/branching.msforms.json`**: synthetic. Owner, tenant and principal
  ids are zero GUIDs, the creator is `owner@example.com`, and form, question
  and tracking ids are placeholders.
- **`msforms/panform-capture-2026-09.msforms.json`**: the owner, tenant,
  creator, OData context, form id and table id are `[redacted]`.
- **`covid-symptom-survey-wave4.qsf`**: Qualtrics owner/creator ID
  `UR_d0dcV2qHLq97nhj` and a CMU mailing-list address
  (`delphi-admin-survey-fb@lists.andrew.cmu.edu`). Both are
  institutional and public upstream. No concern.
- **`openstatspec-dictionary.sps`**, `BEGIN DATA` blocks: synthetic rows only,
  which the upstream fixture policy confirms. No concern.
- **`redcap-demographics.odm.xml`, `openedc-metadata.odm.xml`**: metadata only,
  with no `ClinicalData`. No concern.
- **LimeSurvey `.lss` files**: no `responses`, `tokens` or `timings` sections.
  `ls6-citric.lss` uses the placeholder `foobar@example.com`. No concern.
- All other files: only placeholder addresses (`you@example.com`) and
  invented content.
